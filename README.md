## Защита
В качестве доп. задания для этой лабораторной было сделано разделение монолитного JS-кода на модульную архитектуру: созданы отдельные классы для страниц (MainPage, CoursePage) и переиспользуемых компонентов (CourseCardComponent, CourseDetailComponent, BackButtonComponent). Настроено взаимодействие между ними через проброс родительского элемента и функций-обработчиков (колбэков), что позволило компонентам быть независимыми и переиспользуемыми. Реализована SPA-навигация между страницами без перезагрузки — через очистку innerHTML корневого элемента и рендер новой страницы.

```
// Проброс колбэка в компонент для обработки клика
render() {
    const data = this.getData();
    data.forEach((item) => {
        const productCard = new CourseCardComponent(this.pageRoot);
        productCard.render(item, this.clickCard.bind(this)); // ← колбэк прокидывается
    });
}

// Компонент подписывается на клик по своей кнопке
addListeners(data, listener) {
    document
        .getElementById(`click-card-${data.id}`)
        .addEventListener("click", listener); // ← listener = метод страницы
}

// SPA-переход: очистка родителя и рендер новой страницы
clickCard(e) {
    const cardId = e.target.dataset.id;
    const coursePage = new CoursePage(this.parent, cardId);
    coursePage.render(); // ← полностью заменяет содержимое экрана
}
```
