## Защита
В качестве доп. задания для домашней работы было сделано изменение функции countIdentic — вместо возврата числа повторяющихся элементов функция возвращает объект-словарь countMap в формате «ключ-значение», где ключ — это элемент массива, а значение — количество его вхождений. Такой подход позволяет не только посчитать дубликаты, но и увидеть полную картину распределения элементов в массиве, что удобно для дальнейшего анализа данных.
```
function countIdentic(arr) {
    const countMap = {}; // словарь: ключ = элемент, значение = частота

    for (let i of arr) {
        countMap[i] = (countMap[i] || 0) + 1; // наращиваем счётчик
    }

    return countMap; // возвращаем объект-словарь
}

// Пример вывода:
// [1, 2, 3, 2, 4, 1, 5, 1, 1] → { '1': 4, '2': 2, '3': 1, '4': 1, '5': 1 }

```
